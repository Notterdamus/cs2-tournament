# Турнир по CS2 (FastCup) — таблица и статистика

Локальная страница с турнирной таблицей, сеткой плей-офф, списком матчей и
статистикой игроков. Счёт и стата тянутся автоматически со страниц матчей
FastCup скриптом на Python.

Формат: **круговой этап** (каждый с каждым) → **финал** (1-е vs 2-е место) и
**матч за 3-е место** (3-е vs 4-е место).

```
tournament.json     ← ты редактируешь: команды, составы, ссылки на матчи
update.py           ← собирает данные (скрапит FastCup) и считает таблицу
index.html          ← страница-дашборд (открывать в браузере)
dashboard-data.js   ← генерируется update.py, руками не трогать
cache/              ← уже скачанные матчи + состояние авто-отслеживания (не трогать)
```

---

## 1. Установка (один раз)

Нужен Python 3. Затем в терминале, в папке турнира:

```bash
pip install playwright
python -m playwright install chromium
```

`playwright` — это управляемый браузер: он нужен, потому что у FastCup нет
открытого API и стоит защита Cloudflare, которую обычный запрос не проходит.

---

## 2. Заполни `tournament.json`

### Команды и составы

```json
{
  "id": "t1",
  "name": "Название команды",
  "tag": "TAG",
  "players": [
    { "nick": "ник_на_fastcup", "slug": "" },
    ...
  ]
}
```

- `nick` — ник игрока **точно как на FastCup** (регистр не важен).
- `slug` — необязательно. Это «адрес» профиля: в ссылке
  `cs2.fastcup.net/id123456` или `cs2.fastcup.net/vasya` slug — это `id123456`
  или `vasya`. Если ник на FastCup совпадает с тем, что в конфиге, slug можно
  не заполнять. Если игрок часто меняет ник — впиши slug, тогда сопоставление
  будет надёжным.
- Команд может быть сколько угодно (3, 4, 6, 8…). Расписание «каждый с каждым»
  построится автоматически.

### Расписание

Оставь `"roundRobin": []` — при первом запуске `update.py` сам создаст все пары
и запишет их обратно в файл. Дальше ты просто вписываешь ссылки на сыгранные
матчи.

Один матч в расписании выглядит так:

```json
{
  "id": "rr-1",
  "round": 1,
  "home": "t1",
  "away": "t2",
  "matchId": null,
  "matchIds": null,
  "manualScore": null
}
```

Как внести результат (нужно что-то одно):

| Поле | Когда использовать | Пример |
|---|---|---|
| `"matchId"` | обычный матч на FastCup (Bo1) | `"matchId": 27053086` — можно вставить и полную ссылку `"https://cs2.fastcup.net/matches/27053086"` |
| `"matchIds"` | серия Bo3 из нескольких лобби | `"matchIds": [27053086, 27053090, 27053095]` |
| `"manualScore"` | вписать счёт руками (без статистики игроков) | `"manualScore": [13, 7]` — хозяева : гости |

### Плей-офф

Уже настроен в конфиге:

```json
"playoff": [
  { "id": "third", "name": "Матч за 3-е место", "homeSeed": 3, "awaySeed": 4, "matchId": null, "manualScore": null },
  { "id": "final", "name": "Финал",             "homeSeed": 1, "awaySeed": 2, "matchId": null, "manualScore": null }
]
```

`homeSeed`/`awaySeed` — какие места из таблицы встречаются. Пары подставятся
сами, когда круговой этап доигран. Тебе нужно только вписать `matchId`
(или `matchIds` для Bo3, или `manualScore`), когда матч сыгран.

## 3. Обнови данные

После каждого сыгранного матча вписал ссылку в `tournament.json` и запустил:

```bash
python update.py
```

Что делает:
- достраивает расписание, если оно пустое;
- открывает страницы новых матчей, читает счёт и стату игроков
  (K, D, A, ADR, HS%, рейтинг, входы, клатчи, мультикиллы);
- уже скачанные матчи берёт из `cache/` — быстро;
- пересчитывает таблицу, посев в плей-офф, агрегаты по игрокам;
- пишет `dashboard-data.js`.

Полезные ключи:

```bash
python update.py --no-scrape         # только пересчитать (например, после ручного счёта), без интернета
python update.py --refresh 27053086  # перекачать конкретный матч заново
python update.py --headful           # показать окно браузера (если скрапинг не проходит)
python update.py --regen-schedule    # пересоздать расписание с нуля (после смены состава команд)
python update.py --watch             # онлайн-режим (см. раздел 3b)
python update.py --watch --push      # онлайн-режим + автопубликация на GitHub Pages (раздел 5)
python update.py --live 27054914     # live-счёт идущего матча (см. раздел 3c)
```

Если поменял список команд уже после старта — либо `--regen-schedule`, либо
вручную поставь `"roundRobin": []` и запусти снова.

---

## 3c. Live-счёт во время матча

`--watch` находит матч только **после** завершения. Чтобы показывать счёт **по
ходу игры** — запусти отдельно на время конкретного матча:

```bash
python update.py --live 27054914 --push
```

(вместо `27054914` — ID или ссылка идущего матча; можно несколько через пробел)

Что делает: каждые ~45 секунд читает текущий счёт со страницы матча и
показывает на сайте красную плашку **«🔴 Идёт сейчас · 9:6»** (вверху и на
вкладке «Матчи»). Когда матч заканчивается — сам записывает финал в нужную
клетку расписания и, если больше нет отслеживаемых матчей, завершается.
Ctrl+C — остановить.

Период можно изменить: `--live 27054914 --live-interval 30` (минимум 20 сек).
Секунда-в-секунду не будет — только раз в интервал.

## 3b. Онлайн-режим (авто-отслеживание матчей)

Вместо того чтобы вручную вставлять ссылку на каждый матч, можно дать скрипту
профили капитанов — он сам будет находить сыгранные матчи турнира, определять
какие команды играли, и проставлять счёт.

**Как включить:**

1. У каждой команды впиши `slug` капитана (это адрес профиля: в ссылке
   `cs2.fastcup.net/id1383086` или `cs2.fastcup.net/vasya` slug — это `id1383086`
   или `vasya`). Достаточно одного капитана на команду — он есть в каждом матче
   своей команды.
2. Включи блок `autoTrack` в `tournament.json`:

```json
"autoTrack": {
  "enabled": true,
  "since": "2026-09-05",
  "captains": ["id1383086", "petya", "id999111", "id222333", "vasya2010"]
}
```

- `since` — игнорировать матчи раньше этой даты (формат ГГГГ-ММ-ДД).
- `captains` — список slug'ов капитанов. Если оставить `[]`, скрипт опросит
  профили всех игроков, у которых заполнен `slug` (медленнее).

3. Запусти в онлайн-режиме:

```bash
python update.py --watch                # опрос каждые 3 минуты
python update.py --watch --interval 120 # каждые 2 минуты
python update.py --once                 # один проход и выход
```

Скрипт крутится в цикле: опрашивает профили капитанов, находит новые 5×5 матчи,
определяет команды (по капитану на площадке, а если капитанов нет — по ≥3
игрокам из ростера с каждой стороны), подставляет матч в нужную клетку
расписания (или в пару плей-офф) и пересчитывает таблицу. Страница `index.html`,
если открыта, сама обновится через ~45 секунд. Ctrl+C — остановить.

Достаточно указать в `captains` только капитанов — остальных игроков команд
можно не вписывать. Но если впишешь полные составы (по 5 ников на команду),
статистика игроков будет полнее и надёжнее.

Что скрипт **не** трогает: клетки, где ты уже вписал `matchId`/`manualScore`
руками; матчи-пабы и микс-игры (не находит там двух команд турнира); пары,
которые уже сыграны. Такие матчи он один раз проверяет и заносит в
`cache/_autotrack.json`, чтобы не проверять повторно.

Матчи, добавленные автоматически, помечены на странице зелёным ярлыком «авто».

> Матч появляется в истории профиля **после завершения**, поэтому «онлайн» здесь
> — это «в течение одного интервала опроса после конца матча», а не совсем
> реальное время.

---

## 4. Открой страницу

Открой `index.html` в браузере (двойной клик).

> Если данные не подгружаются при открытии двойным кликом (браузер блокирует
> локальные файлы), запусти в папке турнира:
> ```bash
> python -m http.server 8000
> ```
> и открой `http://localhost:8000/index.html`.

Вкладки: **Таблица**, **Плей-офф**, **Матчи**, **Игроки** (сортировка по клику
на заголовок столбца, фильтр по команде).

## 5. Доступ с телефона (GitHub Pages)

Сама страница — это обычный статический сайт, его можно бесплатно выложить на
GitHub Pages и открывать с любого телефона по ссылке. Скрипт `update.py`
продолжает работать **на твоём компьютере** (в облаке FastCup не скрапится) и
после каждого обновления пушит свежий `dashboard-data.js` в репозиторий —
страница на телефоне подхватывает его сама.

### Разовая настройка

1. Создай на GitHub **публичный** репозиторий (напр. `cs2-tournament`).
2. В папке турнира:
   ```bash
   git init
   git add .
   git commit -m "tournament"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/cs2-tournament.git
   git push -u origin main
   ```
   (первый `push` попросит залогиниться в GitHub — дальше логин запомнится)
3. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a
   branch → Branch: `main` / `/ (root)` → Save**.
4. Через минуту сайт будет доступен по адресу
   `https://ТВОЙ_ЛОГИН.github.io/cs2-tournament/` — открывай с телефона,
   добавь на домашний экран.

`.gitignore` уже настроен: папка `cache/` и служебные файлы в репозиторий не
попадают.

### Во время турнира

Запускай онлайн-режим с автопубликацией:

```bash
python update.py --watch --push
```

Каждый раз, когда находится новый матч, скрипт коммитит и пушит обновление —
GitHub Pages обновляется за ~1 минуту, страница на телефоне сама перезагрузится.

Разово опубликовать после ручного ввода счёта:
```bash
python update.py --no-scrape --push
```

> Компьютер со скриптом должен быть включён и в сети всё время турнира —
> именно он собирает данные. Телефон и зрители смотрят готовую страницу с
> GitHub Pages.

### Локально по сети (без GitHub)

Если все в одной Wi-Fi сети: `python -m http.server 8000` на компьютере, потом
на телефоне открой `http://<IP-компьютера>:8000/index.html` (IP смотри в
`ipconfig`). Работает только в пределах этой сети.

## Частые вопросы

**Матч не читается («не удалось прочитать счёт»)** — матч ещё не завершён на
FastCup, либо страница не догрузилась. Попробуй `python update.py --headful`.

**Ник игрока не подхватился в статистике** — проверь, что `nick` в
`tournament.json` совпадает с ником на FastCup, либо укажи `slug`.

**Ничьи в круговом этапе** — по умолчанию победа 3 очка, ничья 1, поражение 0.
Меняется в `format`. Тай-брейки: очки → личные встречи → разница раундов →
выигранные раунды → победы.

**Нужен второй круг** — поставь `"doubleRoundRobin": true` в `format` и
`python update.py --regen-schedule`.
